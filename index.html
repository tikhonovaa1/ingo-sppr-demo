Импорт / подключаемый источник
Автоматическое заполнение по ИНН — Чекко API через защищённый облачный сервер. Доступность финансов и арбитражей зависит от тарифа. Неподтверждённые показатели не подставляются.
После выбора файла сведения автоматически заполнят поля. XML — для реквизитов ЕГРЮЛ; JSON — для реквизитов и финансовых показателей по подтверждённым данным. Загрузка выполняется только в вашем браузере. При запуске с сервером возможен запрос сведений по ИНН через подключённого провайдера. Прямой бесплатный доступ к ФНС и КАД не гарантируется. Источники и подтверждение

Реквизиты можно импортировать из XML-выписки ЕГРЮЛ, финансовые показатели — из подготовленного JSON по подтверждённой отчётности.
